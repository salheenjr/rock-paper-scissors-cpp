# Rock Paper Scissors Game (C++)

A simple console-based Rock Paper Scissors game built using C++.

This project was created to practice:
- Procedural Programming
- Function Decomposition
- Enums and Structs
- Game Logic Design
- Clean Code Organization
- Random Number Generation

---

## Features

- Play against the computer
- Multiple game rounds (1 to 10)
- Round-by-round results
- Final game statistics
- Winner tracking system
- Console color changes based on results
- Structured and modular code design

---

## Concepts Used

### Procedural Programming
The project is fully built using procedural programming principles without using OOP.

### Divide and Conquer Approach
The game logic is split into small functions where each function handles a single responsibility:
- Reading player input
- Generating computer choice
- Determining round winner
- Printing results
- Managing game statistics

This makes the code easier to:
- Read
- Debug
- Maintain
- Expand in the future

### Enums
Enums are used to improve readability and avoid magic numbers.

### Structs
Structs are used to group related game and round information together.
